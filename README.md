
# 🌈 Animação de Bordas em Degradê

Projeto de botões interativos com bordas animadas em degradê, desenvolvido com **HTML5 e CSS3** como parte de uma atividade prática do curso PROA.

O objetivo é explorar animações e efeitos visuais utilizando exclusivamente CSS, criando botões com bordas multicoloridas que mudam de tonalidade ao passar o cursor sobre eles.

## 🌐 Demonstração

🔗 **[Acesse o projeto online](https://gabrielc0liveira.github.io/Projeto19Proa-AnimacaoBordasDegrade/)**

## Funcionalidades e características

- Dois botões com bordas coloridas em degradê.
- Animações ativadas ao passar o cursor sobre os botões.
- Alteração contínua das cores utilizando o efeito `hue-rotate()`.
- Animações com sentidos opostos de rotação das tonalidades.
- Efeito visual de transição contínua com `@keyframes`.
- Interface com fundo escuro para destacar as cores.
- Bordas arredondadas e conteúdo centralizado.
- Animações desenvolvidas exclusivamente com CSS, sem JavaScript.

## Tecnologias utilizadas

- **HTML5:** estruturação dos botões e elementos da página.
- **CSS3:** estilização, degradês, animações e efeitos de interação.
- **Google Fonts:** utilização da fonte Poppins.

## Aprendizados

Durante o desenvolvimento, foram praticados conceitos como:

- Estruturação e estilização de botões com HTML e CSS.
- Criação de degradês utilizando `linear-gradient()`.
- Aplicação de animações com `@keyframes`.
- Utilização da propriedade `animation` para controlar duração e repetição.
- Aplicação do filtro `hue-rotate()` para alterar tonalidades.
- Criação de efeitos interativos utilizando a pseudoclasse `:hover`.
- Posicionamento de elementos com `position: relative` e `position: absolute`.
- Centralização de elementos com `transform: translate()`.
- Organização de componentes com Flexbox.
- Personalização de bordas com `border-radius`.
- Criação de diferentes efeitos visuais a partir de uma mesma estrutura.
